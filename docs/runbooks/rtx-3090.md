# RTX 3090

Install a working NVIDIA driver and NVIDIA Container Toolkit, then confirm `docker run --rm --gpus all nvidia/cuda:12.6.3-base-ubuntu24.04 nvidia-smi`. Run `LLAMA_ACCELERATOR=cuda ./start.sh`. The CUDA image compiles llama.cpp only for compute capability 8.6 and defaults to all GPU layers plus flash attention. Confirm GPU offload in llama logs and VRAM use with `nvidia-smi`.
